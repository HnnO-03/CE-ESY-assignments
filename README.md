# واجب 1 - تنفيذ مخزن دائري بلغة C

## وصف المشروع
هذا المشروع هو تنفيذ بسيط لمخزن دائري (Circular Buffer) باستخدام لغة C.  
الهدف من الواجب هو فهم طريقة عمل المخزن الدائري وكيفية استخدام المؤشرات head و tail و count للتحكم في البيانات داخل المخزن.

يقوم البرنامج بطلب اسم المستخدم، ثم يضيف النص "CE-ESY" إلى نهاية الاسم.  
بعد ذلك يقوم البرنامج بتخزين كل حرف داخل المخزن الدائري.  
ثم يقرأ الحروف مرة أخرى من المخزن ويعرضها على الشاشة.

## ما الذي قمت بتنفيذه
- مخزن دائري يحتوي على:
  - مصفوفة ثابتة الحجم
  - مؤشر head
  - مؤشر tail
  - عدّاد count
- دوال:
  - `init()` لتهيئة المخزن
  - `isFull()` لمعرفة إذا كان المخزن ممتلئ
  - `isEmpty()` لمعرفة إذا كان المخزن فارغ
  - `writeChar()` لكتابة حرف واحد
  - `readChar()` لقراءة حرف واحد
- التعامل مع:
  - حالة الامتلاء (Overflow)
  - حالة الفراغ (Underflow)
